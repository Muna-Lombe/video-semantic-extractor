Annotation rules

Register policy version

Other requires a descriptive object name. Uncertainty is recorded separately. Extended objects do not count toward COCO adequacy or detector scores.

V1 requires exactly five distinct sources; V2 allows 5–100. Both require 50 non-person COCO objects, five non-person COCO classes, subset and scale coverage, and at most 60% of COCO objects from one source. Extended labels do not satisfy these gates.

These instructions use the object annotation format: COCO classes, live/composited/screen subsets, and pixel boxes. Registration activates this immutable version. Change the version when changing the rules.
