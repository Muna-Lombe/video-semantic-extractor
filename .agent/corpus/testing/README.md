# Testing Corpus

This directory contains testing strategies, test frameworks, test data fixtures, and test automation guidelines.

## 📁 Organization

- `testing-strategy.md` — Overall testing approach
- `unit-testing.md` — Unit test patterns and conventions
- `integration-testing.md` — Integration test approaches
- `fixtures/` — Shared test data and fixtures
- `automation.md` — Test automation frameworks and CI/CD

## 🎯 Purpose

When writing tests, reference this corpus for:
- Testing strategies for different scenarios
- Unit and integration test patterns
- Where to find test fixtures
- Automation setup

## 📝 Contributing

Add documents here when:
- Establishing testing strategies
- Creating test utilities
- Adding test fixtures
- Documenting automation setup
