# Knowledge Corpus

This directory contains domain-specific knowledge, business logic documentation, feature specifications, and integration points.

## 📁 Organization

- `domain-model.md` — Core business concepts and entities
- `features/` — Feature specifications and business logic
- `integrations/` — External system integration guides
- `business-rules.md` — Rules that govern business logic

## 🎯 Purpose

When working on features, reference this corpus for:
- Understanding domain concepts
- Feature requirements and specifications
- Business rules that constrain implementation
- Integration points with external systems

## 📝 Contributing

Add documents here when:
- Defining new domain concepts
- Documenting feature requirements
- Establishing business rules
- Creating integration guides
