# Design Corpus

This directory contains design patterns, architecture guidelines, system design decisions, and technology choices.

## 📁 Organization

- `architecture-principles.md` — Core architectural principles
- `patterns/` — Design patterns used in the project
- `technology-decisions.md` — Technology choices and rationale
- `scalability-guidelines.md` — Performance and scaling considerations

## 🎯 Purpose

When starting a new feature or component, consult this corpus for:
- How to structure the feature
- Which patterns apply
- Performance considerations
- Integration points with existing system

## 📝 Contributing

Add documents here when:
- Establishing a new design pattern
- Making significant technology decisions
- Defining new architectural layers
- Creating scalability guidelines
