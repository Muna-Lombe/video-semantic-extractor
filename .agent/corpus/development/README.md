# Development Corpus

This directory contains code patterns, development workflows, scaffolding templates, and implementation guides.

## 📁 Organization

- `code-style.md` — Code style conventions and best practices
- `workflows/` — Development workflows and processes
- `templates/` — Scaffolding templates for common patterns
- `implementation-guide.md` — Step-by-step guides for common tasks

## 🎯 Purpose

When implementing a feature, reference this corpus for:
- Code style expectations
- Common implementation patterns
- Workflow templates
- Step-by-step guides for specific tasks

## 📝 Contributing

Add documents here when:
- Discovering a useful code pattern
- Documenting a common workflow
- Creating scaffolding templates
- Writing task guides
